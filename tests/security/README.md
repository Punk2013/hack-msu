# Регрессии gateway, задача #9

Набор подготовлен после независимого ревью PR #16. На базе main `c35470e`
исходные проверки давали 11 failed / 2 passed. Исправления в adapter и stream
делают эти сценарии зелёными; skip/xfail нет. Только вымышленная канарейка,
`httpx.MockTransport`, без ключей и внешнего трафика.

```sh
.venv/bin/pytest tests/security -q
```

| Сценарий | Проверяемое поведение |
| --- | --- |
| metadata/user/лишние text-part поля/legacy function_call | HTTP 400 до upstream |
| Ключи JSON Schema и arguments, имена tools/model/идентификаторы | Отказ при обнаружении ПДн, без изменения семантики ключей |
| Неверные типы параметров и вложенных объектов | Отказ до upstream |
| EOF / DONE без завершения choice; length / content_filter / stop | Накопленный tool call не выходит клиенту |
| Обычный ответ с незавершённым tool call | Вызов удалён |
| Многословный alias длиннее 64 символов | Полное восстановление при разных позициях разреза |
| Переполнение буфера SSE | Ошибка, накопленные вызовы не выдаются |

Положительные контроли проверяют маскирование текста, историю инструментов,
схемы и поддерживаемые настройки, а также выпуск завершённого tool call.
В случае ошибки фиксируются уже выданные события: позднее исключение
не скрывает вызов, который успел уйти агенту.

## Ограничения совместимости

Gateway принимает явный набор Chat Completions полей: model/messages/tools,
tool_choice, stream/stream_options.include_usage, temperature/top_p,
max_tokens/max_completion_tokens, n=1, stop, presence_penalty/frequency_penalty,
seed, parallel_tool_calls. Дополнительные поля (включая user, metadata,
response_format, legacy function_call и мультимодальность) дают HTTP 400.
Новые поля требуют отдельного адаптера и регрессионной проверки.

Строки текста и аргументов маскируются. Ключи и управляющие строки, содержащие
обнаруженные ПДн, отвергаются: изменение имени инструмента или ключа JSON
может сломать протокол. Числовые значения внутри произвольного JSON проверяются
как текст и отвергаются при детекции; числовые настройки имеют проверку типа.

В SSE текст целиком буферизуется до завершения choice. Параметр hold сохранён
для совместимости вызовов, но больше не влияет на выдачу. Лимит текста и
аргументов — 1 048 576 символов на choice; превышение прерывает поток.
Это сознательная задержка первого текста ради корректного восстановления
псевдонимов произвольной длины. EOF/DONE без finish_reason отбрасывает
накопленные данные. Инструменты выдаются только при finish_reason=tool_calls.

Эти тесты проверяют маршрутизацию с надёжным подменным трансформером, а не
полноту детектора. Sandbox ОС, vault, реальные клиенты и провайдеры здесь
не проверены. Утверждения о полном покрытии продукта из набора не следуют.
