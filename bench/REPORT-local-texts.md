# Локальный прогон семи текстов — 25.10.2026

Issue #45. Движок main `b50cb22`, Linux/Python 3.12.2; настоящие detect/pseudo/vault.
Дополнительно API интерфейса #42 (`01f3912`) поверх того же движка, отдельный vault.
Все данные специально выдуманы; ни один запрос не ушёл реальной LLM или в интернет.
Upstream — независимый HTTP echo receiver, gateway — настоящий HTTP сервер.

Семь файлов × два режима = 14 сценариев. В 12 принятых запросах текст восстановлен
побайтно, restore COMPLETE, повтор mask стабилен; HTTP-ответ тоже точно исходный,
а upstream-текст совпал с inspected mask. Ещё два запроса с буквальным [PERSON_1]
отклонены: HTTP 500, ни одного запроса у upstream. В UI API те же 12 точных
roundtrip и два отказа. JavaScript интерфейса проверен отдельно, см. ниже.

| Сценарий, каждый в двух режимах | Наблюдение |
| --- | --- |
| Карточка, 4 типа PII | Все четыре размеченных значения скрыты, исходный текст восстановлен |
| Склонения | Полные/короткие формы ФИО заменены; падежи восстановлены точно |
| Два человека с одной фамилией | Разные полные имена и email не перепутались |
| Форматы реквизитов | Сохранились исходные регистр email и формат номера после restore |
| Границы MVP | 4 размеченных значения остались открытыми, upstream verdict LEAK |
| Буквальный [PERSON_1] | Отказ до upstream, HTTP 500, 0 запросов |
| Текст без ПДн | Текст не изменён, точный roundtrip |

## Реальный пример из сохранённого прогона

Исходный текст:

```text
Синтетическая карточка клиента
ФИО: Алексей Дмитриевич Соколов
Email: alexey.sokolov@example.test
Телефон: +7 900 111-22-33
Паспорт: 00 11 123456
Задача: напомнить о встрече 12 ноября в 14:00.
```

Вместо него HTTP upstream получил:

```text
Синтетическая карточка клиента
ФИО: Виктор Павлович Виноградов
Email: elenasemenov12@yandex.ru
Телефон: +7 968 199-36-44
Паспорт: 85 70 881571
Задача: напомнить о встрече 12 ноября в 14:00.
```

Restore вернул исходный текст целиком, включая регистр, пунктуацию и перевод строки.
Значения генерируются для свежей базы: другой запуск может показать другие подставные имена.

## Существенные ограничения и найденная ошибка UI

не входят в текущие четыре типа MVP и ушли HTTP-приёмнику открыто. В обоих режимах
spy нашёл 4 исходных значения, хотя restore COMPLETE и текст восстановлен точно.
`passed` означает совпадение с ожидаемым поведением, а не отсутствие утечек.

но frontend молча переключился на симулятор: чужая карточка Иванова, выдуманные
задержки и COMPLETE. [Request changes #42](https://github.com/Punk2013/hack-msu/pull/42#pullrequestreview-5643195562).
Во время проверки автор обновил #42 до `09a4788`; этот новый UI данным браузерным
прогоном не покрыт. Владелец web/ уведомлён, его файлы не менялись.
