ветка `agent/hornyhydrazine/sandbox-sse-gate`, актуальная база main `fc6bbed`.
Окружение: Linux 5.15.0-198-generic, Python 3.12.2, bubblewrap 0.6.1;
bridge запускается distro Python 3.10. Все персональные данные синтетические.

Проверено реальными процессами и HTTP:

`demo_agent в namespace → UNIX relay → gateway → CorePipeline/detect/pseudo/vault → UpstreamSpy`

У приёмника задан детерминированный сценарий вместо LLM. Он возвращает
read_file → write_file → read_file → write_file → финальный ответ, используя
только текст из HTTP-истории. Gateway и агент проходят обычный production-код.

| Сценарий | HTTP-запросы у провайдера | Запросы с исходными значениями | Исходных полей найдено | Файлы |
| --- | ---: | ---: | ---: | --- |
| Realistic, JSON | 5 | 0 | 0 из 8 | 2 точные копии карточек |
| Realistic, SSE | 5 | 0 | 0 из 8 | 2 точные копии карточек |
| Passthrough, JSON | 5 | 4 | 8 из 8 | 2 точные копии карточек |
| Passthrough, SSE | 5 | 4 | 8 из 8 | 2 точные копии карточек |
| Инъекция ошибки PERSON detector, JSON и SSE | 0 каждый | 0 | — | 0, агент завершился с ошибкой |
| Инъекция ошибки Vault, JSON и SSE | 0 каждый | 0 | — | 0, агент завершился с ошибкой |

Пятый запрос содержит результаты обеих записей: сценарий не заканчивается
проверкой аргументов write_file без реального исполнения. Восстановленные данные
возвращаются в историю локального агента и снова фильтруются перед upstream.
SQLite создан вне экспортируемого workspace; отдельные namespace-регрессии
проверяют сокрытие vault/WAL/SHM, symlink, host credentials и обходной сети.
